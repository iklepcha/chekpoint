# Checkpoint

Веб-приложение для поиска игровых скидок и сравнения цен по регионам.

## Запуск

Требуется Python 3.9+. Сборка и установка пакетов не нужны.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:8000/. После изменения файлов обновите страницу.

## Возможности

Плотный каталог и режим списка, живой поиск, расширенные региональные фильтры, сравнение до четырёх игр, желаемое, коллекция, цели и локальный профиль. Светлая, тёмная и системная темы, адаптивная вёрстка, хедер с возвращением при прокрутке вверх.

## Данные и ограничения

42 игры, 207 предложений, пять регионов. Основная цена в RUB, дополнительная в USD, исходная цена в валюте магазина. Цены — снимок от 28.10.2026, не текущие котировки. Steam представлен шире; Nintendo, PS5 и Xbox пока имеют ограниченное покрытие.

Профиль и списки хранятся в localStorage браузера. База данных, авторизация, автоматическое обновление и Telegram-бот ещё не подключены. Будущие Telegram-уведомления будут бесплатными. Демо графика явно отмечено как вымышленное.

Обложки и материалы игр принадлежат соответствующим правообладателям.

## Обновление снимка

```sh
python3 scripts/import-stores.py
```

Нужны сеть и системные TLS-сертификаты. После импорта проверьте `errors`, покрытие и цены в `dist/catalog.json`.

## Проверка и релиз

```sh
node --check dist/app.js
```

GitHub Actions проверяет JavaScript и состав каталога, затем публикует релиз при изменении `releases/version.txt`. Для новой версии добавьте соответствующий файл заметок в `releases/`. Повторный запуск не заменяет существующий релиз.
