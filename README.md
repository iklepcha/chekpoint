# Checkpoint

Веб-приложение для поиска скидок на игры и сравнения цен по регионам.

## Запуск

Требуется Python 3.9+:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Сборка и установка пакетов не требуются.

## Состав

- `dist/` — интерфейс, стили и снимок каталога: 42 игры, 207 предложений.
- `scripts/import-stores.py` — получение данных официальных магазинов и курсов ЦБ.
- Поиск с живыми карточками, региональные фильтры, системная/светлая/тёмная тема.
- Локальный кабинет, желаемое и ценовые цели сохраняются в браузере.

## Обновление каталога

```sh
python3 scripts/import-stores.py
```

После запуска проверьте `errors` и количество предложений в `dist/catalog.json`. Магазины могут ограничивать частоту запросов. Для Stray и Deep Rock Galactic в текущем снимке получены цены только США. Остальные игры Steam представлены в пяти регионах; покрытие Nintendo, PS5 и Xbox пока ограничено.

## Статус

Это ранняя рабочая версия. База данных, авторизация, автоматическое обновление и Telegram-бот ещё не подключены. Будущие уведомления о скидках будут бесплатными и будут приходить через Telegram. Изображения и данные игр принадлежат соответствующим правообладателям.
