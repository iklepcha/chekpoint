# Checkpoint v0.1.0 — интерактивный прототип

Новый интерфейс для поиска игровых скидок и сравнения региональных цен. Основная цена — в рублях; рядом USD и исходная валюта магазина.

## Что можно протестировать

- Компактная сетка и список игр, платформы Nintendo / PS5 / Xbox / Steam.
- Живой поиск по игре, студии и жанру; затемнение фона и управление с клавиатуры.
- Фильтры страны, цены, скидки, жанра; сохранённые наборы фильтров.
- Сравнение до четырёх игр по регионам.
- Страница игры: предложения магазинов, разница цен, описание, история наблюдений и отдельно отмеченный демонстрационный график.
- Желаемое, коллекция, скрытые игры, локальный профиль, ценовые цели и экспорт списков.
- Системная, светлая и тёмная темы; мобильная вёрстка.
- Хедер скрывается при прокрутке вниз и возвращается при движении вверх.

## Запуск

Распакуйте `checkpoint-v0.1.0.zip`, откройте терминал в папке и запустите:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:8000/. Установка зависимостей не требуется.

## Проверка и ограничения

Проверены поиск, фильтры, региональная матрица, сохранение цели, коллекция, желаемое, темы, мобильный экран и возвращение хедера. Проверка синтаксиса JavaScript выполняется при публикации релиза.

Это прототип: данные пользователя хранятся только в браузере. БД, авторизация, синхронизация и Telegram-бот ещё не подключены; уведомления не отправляются. Каталог содержит 42 игры и 207 предложений из сохранённого снимка от 28.10.2026, цены не обновляются автоматически. Покрытие консолей ограничено. Демо графика использует вымышленные точки и явно подписано.

Обложки и материалы игр принадлежат их правообладателям. Сайт на прежнем адресе Sites этим релизом не обновляется.
